## Этот репозиторий

Здесь находятся исходные файлы официального сайта **[akinside.com](https://akinside.com/)**. Это информационный статический сайт без оплаты заказов и личных кабинетов.

```text
akinside-site/
├── index.html       # Главная страница
├── assets/          # Стили и изображения
├── CNAME            # Привязка к akinside.com
└── README.md        # Описание репозитория
```

Структура приведена для текущей версии и может меняться при развитии сайта.

## Локальный просмотр

Откройте `index.html` в браузере. Для просмотра через локальный сервер при установленном Python:

```bash
python -m http.server 8000
```

Затем перейдите на `http://localhost:8000`.

## Публикация и проверка изменений

Сайт публикуется из ветки `main` через GitHub Pages и использует собственный домен `akinside.com`.

До публикации необходимо проверить отображение на телефоне и компьютере, ссылки, навигацию с клавиатуры, читаемость, отсутствие ошибок браузера и случайно опубликованных конфиденциальных данных.

Для командной разработки рекомендуется работать в отдельных ветках, отправлять изменения на проверку и объединять их с `main` только после одобрения. Правила защиты `main` настраиваются отдельно на GitHub.
